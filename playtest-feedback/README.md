# Edison playtest feedback

Edison’s **Playtest note** action prepares a public GitHub issue with a written note, selected game context and recent in-game events. Submit the prepared issue on this repository while signed in as `guylfe`. It links to the archived Markdown report and its recent game log. Keep the prepared issue title and body so the archive can validate the report.

Each draft has a stable report ID. Retrying the same draft uses the same archive file. Reports include game details shown in the note window. Only enter information you intend to publish.
