0.2.43 · Android-Updates beim Start

Beim Start prüft Android im Hintergrund, ob ein kompatibles Edison-Update verfügbar ist. Wähle im Hauptmenü „Jetzt aktualisieren“ zum Herunterladen oder „Später“, um den Hinweis für diesen Start auszublenden. Die manuelle Suche ist weiterhin in den Einstellungen verfügbar.
